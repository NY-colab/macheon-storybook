# 우리 모둠 동화책방

[동화책방 열기](https://ny-colab.github.io/macheon-storybook/)

세 모둠이 30개 단어 중 다섯 개를 골라 네 쪽짜리 그림동화를 만듭니다. 예시 책 읽기와 원고 직접 넣기는 로그인 없이 사용할 수 있습니다. 책은 한 면짜리 표지에서 시작하고, 화살표로 책장을 넘깁니다.

AI로 글과 그림을 만들려면 강사가 **AI 연결하기**를 누른 뒤 Puter에 로그인합니다. 생성 시 선택한 단어와 원고가 Puter의 AI 서비스로 전송되며 계정의 요금과 이용 한도가 적용됩니다. 생성이 끝날 때까지 탭을 열어 두세요. 삽화 생성이 중단되면 완성된 쪽은 보관되고 다음 시도에서 남은 쪽을 채웁니다.

‘삽화 만들기’를 누르면 네 쪽의 원고를 바탕으로 등장인물 캐릭터시트 한 장을 먼저 그립니다. 각 쪽의 삽화는 같은 시트 이미지를 참고합니다. 원고가 같으면 재시도할 때 저장된 시트를 재사용합니다.

원고와 삽화는 작업한 기기의 같은 브라우저에 저장됩니다. 다른 기기로 자동 동기화되지 않으며 사이트 데이터를 지우면 저장한 책도 삭제됩니다.
